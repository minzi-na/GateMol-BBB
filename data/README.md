# Data

Lightweight, text-based data (SMILES + labels) that git handles well. Large
arrays (precomputed embeddings, weights) live on Zenodo — see `DOWNLOAD.md`.

Label column `p_np`: 1 = BBB+ (permeable), 0 = BBB−. SMILES are canonical.

## Training sets

| File | Rows | Pos | Description |
|---|---|---|---|
| `train_protocol1_internal.csv` | 1677 | — | Protocol I training set (internal only) |
| `train_protocol2_pool.csv` | 9786 | 6791 | Protocol II integrated pool (internal 1677 + external 8109); has a `source` column |

## Holdout evaluation sets (`holdout/`)

Nested similarity-filtered holdout (`329 ⊆ 888 ⊆ 1089` in the paper; the
subsets below are the simfilter09 versions used for cross-protocol comparison).

| File | n | Pos | Subset |
|---|---|---|---|
| `holdout/holdout_total.csv` | 888 | 645 | total |
| `holdout/holdout_nn05.csv` | 329 | 259 | nearest-neighbour sim ≤ 0.5 |
| `holdout/holdout_nn03.csv` | 39 | 28 | nearest-neighbour sim ≤ 0.3 |
| `holdout/holdout_internal.csv` | 179 | 136 | internal-origin slice |
| `holdout/holdout_external.csv` | 709 | 509 | external-origin slice |

## Splits

Scaffold splits are **deterministic from the seed** (10 seeds:
`42,100,…,900`), regenerated by the training code rather than stored. The
`splits/` directory is reserved for exported index files if needed for exact
audit.
